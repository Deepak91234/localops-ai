## Remaining work beyond this release

Provider OAuth sign-in, browser-session imports, JavaScript-only page rendering, enterprise identity/multiuser isolation, advanced retrieval evaluation, and production process sandboxing are not implemented. Actual read-only URL/API snapshots are implemented. Offline acceptance requires a user-controlled WAN disconnect and new local jobs with recorded evidence.
